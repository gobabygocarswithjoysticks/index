## GBG-Tray
Buttons can be velcroed to this tray. 

The tray can be clamped to a PVC pipe.

### Onshape
https://cad.onshape.com/documents/44f6483ba2e32fdd91e296c2/w/0c42af40c7736fb90c2d245d/e/a3a4212259846cc139e36108?renderMode=0&uiState=6a94e691ad19ef6000d9eba6

### Hardware

* 2x 50mm long M5 bolts
* 2x M5 nuts
* 2x ¾” x 1 ¾” piece of 1/16” rubber gasket sheet
* 4x 4-40 nut
* 4x 4-40 1 ¼” machine screw with phillips head
